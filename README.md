# BoardGameVault
BoardGameVault is a modern board game tracker that helps players record matches, manage game collections, and analyze long-term statistics.
Unlike simple score trackers, BoardGameVault focuses on preserving the history of every game night.

Features

🎲 Match Tracking

* Record every board game session
* Support score-based games
* Support winner-only games
* Support cooperative games
* Tie-break support
* Match notes
* Match photos

👥 Player Management

* Player profiles
* Win rate
* Match history
* Head-to-head statistics
* Favorite games

🎮 Game Library

* Import games from BoardGameGeek
* Game images
* Game metadata
* Play history

📊 Statistics

* Most played games
* Win rate
* Monthly statistics
* Yearly statistics
* Longest winning streak
* Average score
* Average play time

☁ Sync

* Cloud synchronization
* Offline mode
* Automatic backup
